Resize the minimap with **F9** (smaller) and **F11** (larger). Choose from **50%, 75%, 100%, 125%, 150%, 175% or 200%**. The frame, markers and clock resize together; terrain zoom stays unchanged.

Both keys can be rebound or disabled in `shroudtopia.json`. Set `mods.minimap_mod.scale_percent` for your startup size (default 100). Hotkey changes last for the current session. F10 also shows a brief On/Off notice.

Close the game and replace `mods/minimap_mod` with the folder from this ZIP. Keep your `shroudtopia.json`. Requires Shroudtopia and the Visual C++ x64 runtime.

Automated rendering, input and configuration checks pass. Gameplay testing of the new sizes is pending.
