# Enshrouded Minimap - Community Edition 0.5.3

The minimap now follows your character's explored areas and shows local weather
beside the world clock. Fog of war, weather and the clock are enabled by default,
with separate live settings for each.

- Live fog covers unexplored terrain and hides original location icons, NPCs,
  shrines, towers and dungeons until explored.
- Players, pings, waypoints, custom pins, placed Flame Altars, tombstones and
  quest markers stay visible through fog.
- A custom pin on an existing marker adds a hollow red diamond around the
  original icon. A pin on empty terrain remains a red flag.
- The weather panel shows Clear, Rain, Snow or Blizzard with a combined
  day/night icon. With weather off, the sun or moon returns beside the time.
- Top-right placement leaves room for quest information. The compact clock
  and weather frame sits against the minimap's lower ornament.

Set `mods.minimap_mod.show_fog_of_war`, `show_clock` or `show_weather` to `false`
in `shroudtopia.json` to hide that feature. Settings refresh while playing.
If exploration data is unavailable, fog remains covered until data arrives or
fog is disabled. Missing weather data hides the weather display.

## Install or update

Requires Windows x64 Enshrouded, Shroudtopia and the Microsoft Visual C++ x64
Redistributable. No server installation is needed; Visual Studio is not needed.

1. Close Enshrouded.
2. Back up `mods/minimap_mod` outside the `mods` directory.
3. Extract `enshrouded-minimap-community-v0.5.3.zip` into the game folder.
4. Keep one `mods/minimap_mod` folder, then start the game.

This minimap-only ZIP preserves `shroudtopia.json`. It includes the runtime
assets, documentation, original license, credits, source revision and checksums.

## Validation

All 470 focused checks pass against Steam client data revision 1076226. User
screenshots show live fog of war, clear daytime, rain and clear nighttime with
the corresponding clock/weather icons. Snow and blizzard are tested in the
renderer but were not separately confirmed in gameplay. All prior tracking,
marker and graphics fixes are included.
