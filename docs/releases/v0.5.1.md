# Enshrouded Minimap - Community Edition 0.5.1

Tombstones now appear on the minimap as small cream skulls. This includes
friends' tombstones supplied by the game. A marker disappears when the grave is
retrieved, and distant graves stay at the minimap's edge.

Death markers are enabled by default. Set `mods.minimap_mod.show_death_markers`
to `false` in `shroudtopia.json` to hide them. The setting updates while you
play. Deaths have their own marker layer, so ordinary POI limits and the
`show_world_markers` setting do not hide them.

This release retains the tracking and graphics fixes, green player arrows and
pings, hollow yellow waypoints, native location icons, altars, NPCs and custom
pins from 0.5.0. The death-marker addition is also submitted in upstream
[PR #6](https://github.com/elxokker/Enshrouded-minimap/pull/6).

## Install or update

Requires Windows x64 Enshrouded, Shroudtopia and the Microsoft Visual C++ x64
Redistributable. No server installation is needed.

1. Close Enshrouded.
2. Back up the existing `mods/minimap_mod` folder outside the `mods` directory.
3. Extract `enshrouded-minimap-community-v0.5.1.zip` into the game folder.
4. Keep one `mods/minimap_mod` folder, then start the game.

The ZIP includes the mod DLL, runtime assets, documentation, license, credits,
build information and checksums. It preserves your `shroudtopia.json` settings
and does not include loaders or other mods.

## Testing

All 187 focused checks pass: 17 tracking, 27 renderer, 58 live-marker and 85
map-feature checks. The layout was checked against Steam client data revision
1076226. On 4 October 2026, gameplay testing confirmed that a friend's tombstone
appears and disappears after retrieval.

The release changes the tested DLL's version and description metadata; the
death-marker implementation is unchanged. Instanced dungeon graves and
dungeon-entrance aggregation remain unverified.
