# Shroudweave Minimap 0.5.15

Compatible with Creative Mode 3.0.0.

## Changes

- Reduced compatibility-check overhead.
- Skipped unused debug-summary work when no summary is needed.
- Preserved north-up orientation, HD map assets, and existing configuration behavior.

## Install

Download the 0.5.15 release archive from GitHub Releases and follow `README-INSTALL.txt`.

This release retains CPU terrain sampling with the Vulkan overlay. It does not claim GPU terrain rendering or a universal performance gain.
