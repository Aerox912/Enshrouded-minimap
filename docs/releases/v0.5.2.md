# Enshrouded Minimap - Community Edition 0.5.2

A world clock now sits below the minimap in a bronze frame with matching cyan
jewels. It displays 24-hour game time, with a gold sun during daylight and a
blue-white crescent at night. The clock reads the game's world time and uses
its sunrise and sunset boundaries, so it follows the server's day/night cycle.

The clock is enabled by default. Set `mods.minimap_mod.show_clock` to `false`
in `shroudtopia.json` to hide it while keeping the minimap. Changes apply while
playing. The footer fits top-right, middle-right and bottom-right placement.

This release includes all earlier tracking and graphics fixes, green player
arrows and pings, yellow waypoint outlines, native map icons, custom pins and
tombstone markers that disappear after retrieval.

## Install or update

Requires Windows x64 Enshrouded, Shroudtopia and the Microsoft Visual C++ x64
Redistributable. No server installation is needed.

1. Close Enshrouded.
2. Back up `mods/minimap_mod` outside the `mods` directory.
3. Extract `enshrouded-minimap-community-v0.5.2.zip` into the game folder.
4. Keep one `mods/minimap_mod` folder, then start the game.

The ZIP includes only the minimap, its runtime assets, documentation, license,
credits and checksums. It preserves your `shroudtopia.json` settings.
