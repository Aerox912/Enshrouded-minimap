# Minimap 0.5.16

Round north-up remains the default, with the HD map, sample step 2 and Creative Mode 3.0.0 guards retained. New configurations start top-right with offset 0. Existing settings are preserved.

- Added an optional north-up square map with the classic gold frame; corrected the DLL-to-shader square flag so terrain fills the square.
- Added configurable player, ping and waypoint glow, with same-colour and contrasting styles. Same-colour is the default, and all glow is enabled by default. Player-arrow glow is stronger; death markers have a dark backplate and red rim.
- Updated renderer startup handling and frame uploads to address missing rendering/borders. These changes are not a claim that every reported border issue is resolved.
- Moved terrain and icon drawing onto GPU paths and cached clock/weather geometry.
- Reduced repeated config reads and marker-cache searches. Unresolved marker positions now use bounded retries while fresh visibility checks and existing guards remain active.

The performance changes may help. Hopefully they improve FPS on affected systems, but an FPS gain is not guaranteed. Tests with different locations or workloads do not establish a before/after improvement.

Square may need a small vertical offset to avoid other HUD elements. An offset of -16 worked for the Journal overlap in one tested setup; adjust it for your display. Positive moves up, negative moves down, and the default remains 0.

This is a complete Minimap package, including its required images and shaders. The Shroudtopia Shroudweave loader remains a separate dependency. Back up before updating and keep your existing configuration.

Native POI-filter mirroring, current-location/region labels and Hollow Halls interior maps remain unfinished and are not included in this release. Linux/Proton issues remain under investigation.
