# Enshrouded Minimap - Community Edition 0.5.0

First community release from [Aerox912's fork](https://github.com/Aerox912/Enshrouded-minimap),
combining the camera/graphics fixes in upstream PR #5 with the player, ping,
waypoint and world-map additions in PR #6.

Original minimap by **elxokker (xoker)**:
[original source](https://github.com/elxokker/Enshrouded-minimap) and
[original Nexus page](https://www.nexusmods.com/enshrouded/mods/97).
This is an independent maintained fork. See [credits](../../CREDITS.md).

## Changes

- Restore local movement and camera-heading tracking on the inspected Steam
  client layout, data revision **1076226**.
- Protect overlay command-buffer reuse with nonblocking GPU fences; rebuild
  resources for recreated swapchains and contain recording/submission faults.
- Show other players as green arrows and pings as green diamonds.
- Show the selected destination as a hollow yellow diamond around its map icon.
- Mirror the game's world-map locations, altars, NPC markers and custom pins.
- Use original location icons by default. Gold frames remain selectable with
  `icon_style: "world-map"`.
- Add configurable terrain lighting and heading smoothing, plus zoom levels
  from -3 through +7.

## Requirements and installation

Windows x64 Enshrouded, [Shroudtopia 0.1.1](https://www.nexusmods.com/enshrouded/mods/43),
and the [Microsoft Visual C++ x64 Redistributable](https://aka.ms/vc14/vc_redist.x64.exe).
Visual Studio is only needed to compile source, not to play. No server-side
installation is required. EML alone cannot load this native DLL.

1. Close the game. Install Shroudtopia if it is not already installed.
2. Back up any existing `mods/minimap_mod` folder outside the `mods` directory.
3. Extract `enshrouded-minimap-community-v0.5.0.zip` into the Enshrouded game folder.
4. Confirm the DLL is at `Enshrouded/mods/minimap_mod/minimap_mod.dll`.
5. Start the game. Existing `shroudtopia.json` settings are preserved.

`F10` or numpad `*` shows/hides the minimap. `+`/`-`, including numpad keys, zoom.
The default position is bottom-right; top-right and middle-right are also
available in `mods.minimap_mod.position`. On keyboard layouts where the main
`+`/`-` keys differ, use the numpad keys.

To remove this mod, close the game and remove `mods/minimap_mod`. Leave the loader
installed if other mods use it. To roll back, restore the backed-up mod folder.

## Validation and compatibility

The combined changes passed **158 focused checks** and were reported working in
gameplay testing on 2026-10-04, with original icons selected. The final icon
default was also checked by the automated suite. The release updates version
metadata and packaging without changing that renderer or marker behavior.

Remote players can only appear where their transforms are available to the
client. Other game layouts and executable variants are unverified. A future
game update can require new layout checks. Individual extended-session and
display-sleep results were not separately recorded; this release does not claim
to eliminate every crash or improve measured FPS.

The ZIP contains this minimap and its runtime assets, documentation, credits,
MIT license, build information and file checksums. It contains no other mods,
personal configuration, saves or mod-loader binaries.
